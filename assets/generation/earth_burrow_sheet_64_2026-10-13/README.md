# Ассеты биома «Земляные норы»

Дата: 2026-10-13. Созданы встроенным imagegen по стилю существующих тайлов Godot.
Финальный набор: `assets/tiles/earth_burrow/series_01/`.

16 непрозрачных PNG 64×64: восемь полов и восемь стен.
Атлас `atlas_64.png` имеет размер 256×256 и раскладку 4×4.
Первые две строки — пол, последние две — стены; порядок указан в manifest.json.
Для игровых PNG используется фильтрация nearest и масштаб 1:1.

Пол включает утоптанную землю, износ, мелкие камни, сухие трещины, сырость,
светлую глину, прижатые корни и рыхлую крошку. Стены включают плотный грунт,
трещину, вросший корень, камни в земле, слои глины, сырость, осыпь и корни.
Основной пол — `01_floor_packed.png`, основная стена — `09_wall_loam.png`.
Для спокойного повторения рекомендуется 80% основной поверхности;
остальные 20% распределяются между семью вариантами каждого типа.

Ходы собираются из клеток пола среди клеток стен: прямые проходы, повороты,
развилки и расширения используют эти же поверхности. Геометрию и
проходимость задаёт карта, а не изображение туннеля внутри отдельного тайла.
Набор сохранён отдельно и ещё не подключён к игровой сцене.

## Исходники и промпты

- [Первый промпт](generation_prompt.txt) и `source_v1.png` — исходная генерация по существующему каменному атласу.
- [Уточнение грунта](generation_prompt_v2.txt) и `source_v2.png` / `source.png` — сплошная земля вместо каменных сегментов.
- [Уточнение базовых поверхностей](generation_prompt_v3.txt) и `source_v3.png` — финальный исходник с более спокойным базовым полом и стеной.
- [Финальный рецепт](recipe_v3.json) — нарезка high-res листа до пикселизации и SHA-256 исходника.
- [Соответствие цветов](earth_recolor.json) — замена пяти красноватых совпадений палитры на нейтральные земляные оттенки AAP64.

## Пайплайн

1. `source_v3.png` нарезается по `recipe_v3.json`.
2. Штатный `pixel_pipeline.py` восстанавливает сетку 64×64 и сводит цвета к AAP64 без дизеринга. Результат: `processed_v3/final/`.
3. По `earth_recolor.json` заменяются только RGB соответствующих пикселей. Все исходные и целевые цвета входят в AAP64; размер и alpha сохраняются. Результат: `earth_aap64/final/`.
4. Штатный `grade_terrain.py` применяет RGB × 0.75, затем Gaussian blur 0.5px один раз. Результат: `terrain_neutral_25_blur05/final/`.
5. Эти PNG копируются в каталог биома, без изменения размера или дополнительного затемнения.

Команды из корня проекта, в новые или пустые папки результатов:

```bash
python3 tools/pixel_processing_complete_2026-10-12/src/pixel_pipeline.py assets/generation/earth_burrow_sheet_64_2026-10-13/recipe_v3.json -o /tmp/earth_burrow_aap64
# Между этапами применить пять точных RGB-замен из earth_recolor.json.
python3 tools/grade_terrain.py assets/generation/earth_burrow_sheet_64_2026-10-13/earth_aap64/final -o /tmp/earth_burrow_graded
python3 tools/pixel_processing_complete_2026-10-12/src/assemble_preview.py /tmp/earth_burrow_graded -o /tmp/earth_burrow_atlas.png --columns 4
```

## Проверка и превью

`processed_v3/qa.json` и `earth_aap64/qa.json` подтверждают 16 PNG, размер
64×64, полную непрозрачность и AAP64 до затемнения. `installation.json`
подтверждает совпадение хешей установленных PNG с финальными обработанными
источниками, а также размер атласа 256×256.

`preview_3x.png` показывает финальный лист с nearest-увеличением только для просмотра.
`burrow_layout_preview.png` — офлайн-композиция поля 11×11 клеток с существующим
героем в масштабе 1:1. Это превью ассетов, не скриншот запущенной игры.
Схема, размещения и приблизительная обводка границ стен записаны в
`preview_layout.json`; обводка не запечена в игровые PNG.
