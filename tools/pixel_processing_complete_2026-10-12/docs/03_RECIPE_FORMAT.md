# Формат рецептов

Рецепт — JSON с `version: 1`. Все файловые пути в нём вычисляются
от папки самого рецепта, поэтому архив можно распаковать в другое место.

## Основные поля

| Поле | Значение |
|---|---|
| `kind` | `sheet` или `single` |
| `source` | PNG для обработки |
| `source_sha256` | необязательная проверка входного PNG |
| `reference_dir` | необязательная папка эталонных выходов |
| `layout` | параметры поиска промежутков или точные границы |
| `chroma` | настройки удаления фона; отсутствие отключает этап |
| `reconstruction` | настройки сетки и чтения цвета |
| `palette` | `aap64`, `image`, `none` |
| `outline` | цвет AAP64 и соседство; отсутствие отключает обводку |
| `canvas` | размер холста и базовая линия |
| `crop` | размер и позиция кадра без рескейла |
| `sprites` | список имён и индивидуальных настроек в порядке рядов |
| `fit_canvas_candidates` | разрешить выбор сильного кандидата, помещающегося в холст |
| `preview_columns` | количество колонок итогового листа |

## Автоматическая нарезка

```json
{"rows":4,"columns":4,"empty_fraction":0.01,"minimum_gap":5}
```

Пустыми считаются полосы, в которых видимые пиксели занимают не более
`empty_fraction` поперечного размера. Поиск выбирает пустой промежуток
около ожидаемой границы. Если промежутка нет, нужны явные координаты.

## Точная нарезка

```json
{
  "row_boundaries":[0,303,604,884,1254],
  "column_boundaries":[
    [0,304,623,926,1254],
    [0,297,605,887,1254],
    [0,324,614,929,1254],
    [0,292,606,868,1254]
  ]
}
```

Координаты в high-res пикселях; правый и нижний край исключаются.

## Сетка

Поиск сетки:

```json
{"min_cell":4.5,"max_cell":5.5,"inset":0.18,"alpha_coverage":0.5}
```

Фиксированная известная сетка, как в одиночных старых примерах:

```json
{"grid":[162,162],"inset":0.18}
```

Фиксированные период и фаза для точного повторения:

```json
{"grid":{"cell_size_x":5.0,"cell_size_y":5.0,"offset_x":0.0,"offset_y":3.5}}
```

`skip: true` позволяет начать со входа, который уже является настоящим
низкоразрешённым пиксельным PNG, например для отдельной обработки кракена.

## Существа

```json
{
  "name":"08_armored_war_boar",
  "flip_horizontal":true,
  "reconstruction":{"min_cell":4.8,"max_cell":5.5}
}
```

Индивидуальная `reconstruction` переопределяет общие настройки. Имена
должны быть уникальными и содержать латинские буквы, цифры, `_` или `-`.
Количество существ должно совпадать с числом фрагментов.

## AAP64, обводка, холст и crop

```json
{
  "palette":"aap64",
  "outline":{"color":"242234","neighbors":8},
  "canvas":{"size":[66,66],"baseline":63}
}
```

Обводка внутренняя, alpha неизменна. `baseline` — bottom-exclusive
координата нижней границы видимого bbox. Она не является номером нижнего
видимого пикселя.

```json
{"size":[96,96],"x":58,"y":34,"shift_y":8}
```

Если `x` и `y` не заданы, crop начинается по центру. Широкий или высокий
спрайт не обрезается автоматически при выравнивании: запуск выдаёт ошибку.
