# Проверка и воспроизводимость

## Тесты

```bash
env PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Десять тестов проверяют смещённую сетку, чтение RGBA без прозрачной
магентовой примеси, alpha обводки, отражение, отсутствие обрезки при
выравнивании, сдвиг crop, неодинаковые промежутки рядов, корректность
границ, ошибку QA и полный интеграционный запуск.

## Настоящие исходники

```bash
python3 src/verify_examples.py --report verification.json
```

Девять рецептов дают 69 точных сравнений. Третий и четвёртый листы
дополнительно проверены на полное равенство RGBA всех 32 финальных тайлов,
включая прозрачные пиксели.

Кроме общего запуска проверяется настоящая цепочка отдельных CLI:
нарезка, chroma key, реконструкция каждого фрагмента, AAP64, обводка,
отражение, холст, сборка листа, валидация и сравнение. Она повторяет ещё
16 эталонных тайлов четвёртого листа и его превью.
Отдельной командой проверяется также кадрирование портрета волка.

`sheet03.json` и `sheet04.json` заново ищут фазу каждого high-res фрагмента.
`sheet03_replay.json` и `sheet04_replay.json` используют сохранённые точные
периоды и фазы. Оба режима возвращают принятые изображения.

## QA финальных листов

- 16 тайлов 66×66;
- alpha только 0/255;
- нижний bottom-exclusive bbox равен 63;
- все видимые RGB принадлежат AAP64;
- обводка не меняет alpha;
- выравнивание не обрезает bbox;
- совпадение видимых RGB и alpha с эталоном;
- дополнительный флаг `rgba_pixels_exact` проверяет также скрытые RGB.

При ошибке любого условия общий запуск завершается кодом 1 и сохраняет
`qa.json` и `run.json` со статусом ошибки. Повторный запуск в непустой
каталог запрещён, чтобы не смешивать новые результаты со старыми.

## Консистентность двух листов

| Метрика | Серия 03 | Серия 04 |
|---|---:|---:|
| Средняя ширина bbox | 54.19 | 51.44 |
| Средняя высота bbox | 50.38 | 47.56 |
| Средняя видимая яркость | 0.354 | 0.347 |
| Доля тёмных пикселей | 43.1% | 43.3% |
| Цветов AAP64 | 63 | 59 |

Пересечение палитр — 59 цветов; Jaccard — 0.937. `compare_sets.py`
пересчитывает эти метрики и создаёт сравнение рядом. Метрики описывают
яркость, массу и цвета, но для нового листа всё равно нужно посмотреть
на читаемость лица, лап, оружия и тонких элементов.

## Целостность архива

`SHA256SUMS` содержит хеш каждого файла комплекта, кроме самого списка.
ZIP проверяется при сборке. Полный состав перечислен в `MANIFEST.json`.

## Пересборка из исходного проекта

```bash
python3 build_pixel_bundle.py --project /path/to/assetgen \
  --output /path/to/pixel_processing_complete \
  --generated /path/to/original/generated_images
```

Сборщик требует новый каталог и новое имя ZIP. Полигональные,
Delaunay- и треугольные эксперименты принадлежат другому конвейеру и
не включаются в пиксельный комплект.
